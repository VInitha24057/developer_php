# Developer Internship Assignment

## Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery
- PHP
- MySQL
- MongoDB
- Redis

## Requirements

- XAMPP
- PHP 8+
- MySQL
- MongoDB
- Composer

## Installation

1. Clone project
2. Copy into htdocs
3. Import internship.sql
4. Run Composer
5. Start Apache & MySQL
6. Open localhost/DeveloperInternship/register.html

✔ User Registration

✔ Login
